# QFF 2026 Hackathon — Q-LINK

**Qiskit Fall Fest · QUICK · 고려대학교**

Alice, Bob, Charlie의 세 실험실을 연결하는 양자 네트워크 실험에 참여하세요. 측정과 얽힘 자원을 점검하고, 양자 텔레포테이션으로 상태를 전송한 뒤, GHZ–Mermin 게임에서 세 실험실의 협력 성능을 확인합니다.

**[Google Colab에서 문제지 열기](https://colab.research.google.com/github/equivoque-jk/qff-2026-Challenge-Quiz/blob/main/QFF_Challenge_Colab.ipynb)** · [문제지 파일·다운로드](https://github.com/equivoque-jk/qff-2026-Challenge-Quiz/blob/main/QFF_Challenge_Colab.ipynb)

문제 설명, 이미지, 실험 코드와 채점 도구 설치 셀이 모두 **`QFF_Challenge_Colab.ipynb` 하나에 들어 있습니다.** 파일을 내려받으려면 위 문제지 파일 화면에서 **Download raw file** 버튼을 누르세요.

## 시작하기

1. Colab에서 문제지를 열고, 풀이를 보관할 수 있도록 **자신의 사본으로 저장**하세요. CPU 런타임으로 진행할 수 있습니다.
2. **준비 A 셀만 먼저 실행**하세요. 필요한 패키지와 실험 도구가 설치됩니다. 최초 설치에는 인터넷 연결이 필요합니다.
3. 재시작 안내가 나오면 **런타임 → 세션 다시 시작**을 선택한 뒤 **준비 A를 다시 실행**하세요.
4. 준비 완료를 확인한 뒤 준비 B·C·D와 해당 문제에 필요한 제공 도구·문제 셀을 순서대로 실행하세요.

VS Code나 Jupyter에서도 같은 노트북을 사용할 수 있습니다. **Python 3.10–3.13** 커널을 선택하고 준비 A부터 실행하세요. 로컬 환경은 Python 3.12를 권장합니다. 재시작 안내가 나오면 커널을 재시작한 뒤 준비 A를 다시 실행하면 됩니다.

## 문제 구성

| 구분 | 내용 | 배점 |
|---|---|---:|
| 1. 측정과 얽힘 | 측정 기저에 따른 상태 구별과 Bell·GHZ 자원 준비 | 30점 |
| 2. 양자 텔레포테이션 | 고장 회로 진단, 전송 회로 복구와 검증 | 40점 |
| 3. GHZ–Mermin 게임 | 고전 전략과 양자 전략의 승률 비교 | 30점 |
| 선택 2-5 | 두 qubit의 전체 상태 전송 | 추가 12점 |
| 선택 3-5 | 위상 오류가 있는 자원의 게임 성능 분석 | 추가 8점 |

기본 문항은 **100점**, 선택 심화는 **추가 20점**입니다. 선택 문항은 원하는 문제만 풀 수 있으며, 풀지 않아도 기본 문항 점수에는 영향을 주지 않습니다.

## 풀이 방법

- 답안 함수의 **`TODO BEGIN`과 `TODO END` 사이**에 코드를 작성하세요. 해당 영역의 `raise NotImplementedError(...)`를 지우고 자신의 구현으로 교체하면 됩니다.
- 함수 선언, 제공된 초기화 코드, 마지막 `return`, 실행·채점 셀은 그대로 두세요. 답안 함수는 선택 문항을 포함해 총 23개입니다.
- 각 문항의 **반환 형식과 채점 사항**을 확인하세요. 수치 답안에는 표본 실험의 추정치를 복사하지 말고, 문제에서 요구하는 정확한 값을 계산해 반환하세요.
- 실험 메모에는 계산 과정과 결과를 해석한 내용을 적으세요. 실험 메모와 마지막 개통 보고서는 채점 대상이 아닙니다.

**2-1과 선택 2-5에서 제공된 고장 회로의 실패 메시지는 의도된 결과입니다.** 메시지를 단서로 결함을 찾고, 수정한 회로가 검증을 통과하는지 확인하세요.

## 채점 및 제출

1. 답안을 저장한 뒤 **런타임 → 모두 실행**을 선택하세요. VS Code·Jupyter에서는 **Run All**을 사용하면 됩니다. 작성하지 않은 선택 문항의 TODO는 그대로 두세요.
2. 마지막 셀에서 **기본·추가 점수와 미완성·오류 항목**을 확인하세요. 문제별 실험 출력만으로 모든 답안 함수가 검증되는 것은 아니므로 마지막 채점 결과도 확인해야 합니다.
3. 마지막 셀이 생성한 **제출 ZIP**을 내려받고, **풀이를 작성한 노트북을 `.ipynb`로 별도 저장**하세요. 노트북은 제출 ZIP에 포함되지 않습니다.
4. **제출 ZIP과 작성한 `.ipynb` 두 파일을 행사에서 안내한 제출처에 함께 제출**하세요. 채점 셀을 실행하는 것만으로 제출이 접수되지는 않습니다.

답안을 수정하고 다시 모두 실행하면 새 실행 ID로 결과가 저장됩니다. **마지막 채점 결과의 실행 ID와 제출 ZIP이 일치하는지 확인**하세요.

## 실행 중 문제가 생겼다면

- **설치가 실패할 때:** 준비 A의 오류 메시지와 인터넷 연결을 확인한 뒤 다시 실행하세요.
- **세션이나 커널을 재시작했을 때:** 화면에 예전 출력이 남아 있어도 변수와 함수 정의는 사라집니다. 준비 A부터 필요한 셀을 순서대로 다시 실행하세요.
- **제출 ZIP이 다운로드되지 않을 때:** 마지막 셀에 표시된 다운로드 링크나 저장 경로에서 파일을 받으세요. VS Code·Jupyter에서도 같은 경로를 이용할 수 있습니다.

문항별 조건과 제출물에 관한 자세한 안내는 노트북을 확인하세요. 진행 중 해결되지 않는 문제가 생기면 오류 메시지와 해당 셀을 운영진에게 보여 주세요.
